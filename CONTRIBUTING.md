# Katkı rehberi

1. Değişikliği küçük ve denetlenebilir tutun.
2. Mühendislik katalog satırında resmî GTS NX alan adını, doğrudan kaynak konumunu, deney standardını ve sınırlamayı birlikte belirtin.
3. Parametre değeri, korelasyon veya sessiz varsayım eklemeyin.
4. Tekilleştirme anahtarındaki mühendislik eksenlerinden birini değiştiriyorsanız ayrışma ve birleşme testlerini birlikte ekleyin.
5. `npm run verify`, `npm run test:exports` ve `npm audit` yeşil olmadan pull request açmayın.

Mühendislik satırları bağımsız uzman imzası olmadan yerleşik paketin `review-required` durumunu değiştiremez.
