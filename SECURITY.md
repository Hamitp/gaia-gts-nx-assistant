# Güvenlik politikası

Güvenlik açığını herkese açık issue içinde istismar ayrıntılarıyla paylaşmayın. GitHub Security Advisory üzerinden özel rapor gönderin ve etkilenen sürüm, tekrar adımları ile olası etkiyi belirtin.

GAIA; renderer'da Node.js erişimini kapatır, dar preload API kullanır, proje/bilgi paketi girdilerini ana süreçte doğrular ve dışa aktarımı etkin bilgi paketinden yeniden hesaplar. İmzalanmamış Windows inceleme sürümlerinde SmartScreen uyarısı görülebilir.
